# Security

Skew is pre-audit and must not be used to move real funds.

Please do not open a public issue for a vulnerability. Send a private report
through GitHub's security advisory flow for this repository. Include the
affected object or component, reproduction steps, impact, and any proposed
mitigation. Do not include production credentials, personal data, or real user
funds in a report.

Public examples are non-production fixtures. They contain no private keys and
do not represent settled transactions.
